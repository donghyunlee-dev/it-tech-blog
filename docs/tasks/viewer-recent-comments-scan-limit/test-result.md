# test-result — 최근 댓글 조회 범위 제한

| 항목 | 방법 | 결과 |
|---|---|---|
| Lint | `npm run lint` | 통과 |
| 빌드 | `rm -rf .next && npm run build` | 통과 |
| 실 데이터 회귀 확인 | `npm run start`로 프로덕션 빌드 기동 후 홈 화면 curl | 사이드바에 기존과 동일하게 실 테스트 댓글("[테스트] 이 댓글은 Claude가...")이 "Claude 테스트" 작성자로 정상 노출됨 — 게시 문서가 3건뿐이라 스캔 범위(10) 안에 전부 포함되므로 동작 차이 없음 확인 |

## 커버되지 않은 부분

- 게시 문서가 스캔 범위(10)를 실제로 초과하는 상황(예: 11건 이상)은 현재 실 게시 문서가 3건뿐이라 재현할 수 없다 — `posts.slice(0, RECENT_COMMENTS_SCAN_LIMIT)`가 배열을 정확히 자르는 것은 표준 JS 동작이라 코드 레벨로는 의심할 이유가 없다고 판단해 별도 단위 테스트를 추가하지 않았다.
