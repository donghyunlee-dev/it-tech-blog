# test-result — 카테고리/태그 노출

| 항목 | 명령/방법 | 결과 |
|---|---|---|
| 실데이터 조사 | `curl .../api/v2/pages/{id}/labels`로 게시 문서 3건 직접 조회 | 1건은 레이블 6개(`ai`/`업무`/`활용`/`개인`/`설정`/`가이드`, 다른 두 게시 문서 중 하나도 동일 레이블 6개 공유), 나머지 1건(`컴포넌트 테스트`)은 레이블 없음 — 다중 자유 태그이며 전부 없을 수도 있음을 확인 |
| Lint | `npm run lint` | 통과 |
| 빌드 | `rm -rf .next && npm run build` | 통과 |
| 홈 화면(레이블 있는 문서) | 브라우저로 히어로·카드 확인 | "AI · 업무 · 활용" 태그 라인이 제목 위에 정상 노출(소문자 `ai`가 `.kicker`의 `text-transform: uppercase`로 자동 대문자화됨) |
| 홈 화면(레이블 없는 문서, "컴포넌트 테스트") | 같은 화면에서 확인 | 태그 라인이 렌더링되지 않음(빈 자리 없이 자연스럽게 생략) — 콘솔 에러 없음 |
| 상세 페이지 | 레이블 있는 문서 상세 확인 | 제목 위 태그 라인 정상 노출 |
