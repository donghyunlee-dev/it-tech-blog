# test-result — 사이드바 "최근 댓글" 실데이터

| 항목 | 명령/방법 | 결과 |
|---|---|---|
| Lint | `npm run lint` | 통과 |
| 빌드 | `rm -rf .next && npm run build` | 통과 |
| 빈 상태 확인 | 브라우저로 홈 화면 확인(현재 실 게시 문서 3건 모두 댓글 0건) | "최근 댓글" 섹션 자체가 렌더링되지 않음(정상 — 빈 배열이면 컴포넌트가 `null` 반환), 콘솔 에러 없음. 게시 문서 3건 각각에 대해 댓글 조회 API가 호출됐고 전부 정상 응답(빈 배열) |

## 검증하지 못한 것

- **댓글이 실제로 있을 때의 노출**: 현재 운영 Confluence 스페이스에는 댓글이 하나도 없다. 검증을 위해 임의로 테스트 댓글을 남기는 것은 실 서비스 데이터에 쓰기 작업을 하는 것이라 이번에도 수행하지 않았다(이전 태스크들과 동일한 원칙). 실제 댓글이 하나라도 달리면 다음 홈 화면 새로고침(ISR 60초 이내)에 정상 노출되는지 재확인이 필요하다.
- **부분 실패 시나리오**(게시 문서 중 하나만 댓글 조회 실패)는 코드 리뷰로만 확인했다(`try/catch`로 개별 문서 실패를 빈 배열로 흡수, 전체 실패로 번지지 않음) — 실제 API 실패를 인위적으로 재현하지는 않았다.
