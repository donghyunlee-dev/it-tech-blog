# spec — 상세 페이지 읽기 경험 개선 (헤더 고정 / TOC 활성 표시 / 코드·콜아웃 디자인 / 표 폭 / 히어로 이미지)

사용자가 실제로 페이지를 읽으며 지적한 6건. 전부 코드로 재현해 원인을 확인했다.

## 1. 제목/헤더가 고정되지 않아 목록으로 돌아가기 어려움

`.slim-header`(상세 페이지 상단, "← 목록으로" 링크 포함)가 `position: static`이라 스크롤하면 같이 사라진다. 글을 읽다가 목록으로 돌아가려면 맨 위로 다시 스크롤해야 한다.

## 2. TOC에서 중제목(h2)을 클릭해도 소제목(h3)이 활성 표시됨

`TableOfContents.tsx`의 스크롤스파이가 `ACTIVE_LINE_OFFSET = 120`(px) 이내에 있는 헤딩 중 "마지막 것"을 활성으로 표시하는데, h2 TOC 링크를 클릭해 그 h2로 점프하면 바로 뒤에 있는 h3도 우연히 120px 안에 들어와 h3가 활성으로 덮어써진다. 실측(`컴포넌트 테스트` 문서, h2 클릭 직후): h2 top=0.2px, h3 top=69.8px — 둘 다 120px 미만이라 h3가 최종 active로 남는다.

## 3. 코드 블록이 단순 회색 배경뿐이라 기술 블로그에 안 어울림

현재 `.article-body pre`는 배경(`var(--surface-muted)`)·라운드·패딩만 있고, 언어 표시·복사 버튼·구분되는 톤이 없다. Confluence 코드 *매크로*로 온 것만 `shiki`로 하이라이팅되고(언어색은 있음), 배경 자체는 콜아웃·인용문과 똑같은 회색이라 본문의 다른 카드형 요소와 시각적으로 구분이 잘 안 된다.

## 4. 콜아웃(정보/주의 등)이 왼쪽 컬러 라인 — AI 안티패턴

Phase 2에서 추가한 `.viewer-panel-*`의 `border-left` 컬러 라인이, 사용자가 지적한 "AI 생성 UI 안티패턴"(좌측 그라데이션/컬러 라인 남용) 목록에 해당한다는 피드백. 좌측 라인 없이 색을 구분하는 디자인으로 바꿔야 한다.

## 5. 표 전체 폭이 Editor에서는 꽉 차는데 블로그에서는 좁게 나옴

원인 확인됨: Phase 3에서 `table.viewer-table`에 가로 스크롤을 주려고 `display: block; overflow-x: auto`를 썼는데, `display:block`이 브라우저의 테이블 자동 폭 분배 알고리즘을 깨버린다. 실측: 테이블 박스 자체는 936px(꽉 참)이지만 실제 마지막 셀의 오른쪽 끝은 237px에서 끝나 나머지 ~700px가 빈 공간으로 남는다(셀에 텍스트가 적을수록 컬럼이 내용 크기로만 줄어들기 때문). Phase 3 자체가 회귀를 만든 것 — 되돌리고 다른 방식으로 가로 스크롤을 구현해야 한다.

## 6. 히어로(첫 이미지)가 큰 경우 화면을 너무 많이 밀어냄

`.article-hero img`가 `width:100%; height:auto`뿐이라 원본 비율 그대로 나온다. 세로로 긴 스크린샷이 히어로로 잡히면 제목 바로 아래에서 화면 전체를 잡아먹는다. 게다가 카드 프레임 없이 그냥 이미지라 "이게 히어로(대표 이미지) 영역이다"라는 시각적 신호가 없다.

## 범위 (In Scope)

- `.slim-header`를 sticky로 고정(1).
- TOC 클릭 시 즉시 해당 헤딩을 active로 표시(2).
- 코드 블록에 언어 라벨 + 복사 버튼 + 구분되는 톤을 주는 "코드 창(chrome)" 디자인 도입(3). Confluence 코드 매크로든 Editor 네이티브 `<pre>`든 동일하게 적용.
- `.viewer-panel` 좌측 라인 제거, 아이콘 배지 + 배경 톤으로만 구분(4).
- 표 가로 스크롤을 래퍼 `<div>`로 옮기고 표 자체는 `display:table`을 유지해 폭 분배 정상화(5).
- `.article-hero`를 고정 비율 배너로 바꾸고 `object-fit:cover`로 크롭(6).

## Out of Scope

- 홈 화면(`.utility-bar`/`.masthead`) 고정 — 이번 요청은 상세 페이지 한정.
- 코드 블록 언어 자동 감지(네이티브 `<pre>`는 언어 정보가 원래 없음, 기존 한계 유지).
- Editor 쪽 변경(별도 저장소).

## 수용 기준

- [ ] 상세 페이지에서 스크롤해도 "← 목록으로" 링크가 항상 보인다.
- [ ] TOC에서 h2를 클릭하면 h2가 active로 표시된다(h3로 안 바뀜).
- [ ] 코드 블록에 언어 라벨과 복사 버튼이 보이고, 클릭하면 실제로 클립보드에 복사된다.
- [ ] 콜아웃에 좌측 컬러 라인이 없다.
- [ ] 표가 셀 내용과 무관하게 본문 폭을 꽉 채운다(빈 칸이 있어도).
- [ ] 히어로 이미지가 세로로 길어도 일정 높이 안에서 크롭되어 보인다.
- [ ] `npm run lint`/`npm run build` 통과, 회귀 없음(기존 Phase 1~4 요소 재확인).
